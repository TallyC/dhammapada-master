# 法句經・故事與偈

用「讀、詞、義、行」四圈，帶人從故事走進偈頌、字詞、義理，再落到生活實踐的法句經學習工具。

- 網站：https://tallyc.github.io/dhammapada-master/
- 程式：https://github.com/TallyC/dhammapada-master
- 手機可「加入主畫面」當 App 使用（設定頁有安裝說明）。

> 本文件是第一版（對應程式 V-6.001），依目前程式與「經典」專案內的《法句經工具地圖》整理。細節若與程式不同，以程式為準。

## 它能做什麼

- **五個分頁**：首頁（今日經文、精進、全部 39 品）、學習（讀、詞、義、行）、金句（圖卡）、延伸（影音與文獻）、設定。
- **全文閱讀**：大正藏 T210《法句經》39 品；其中 16 品另有故事導讀。
- **個人使用**：最近閱讀、完成狀態、心得、收藏，並可備份與還原。
- **圖卡**：把偈頌做成圖片分享，可選字體與字級。
- **聽誦**：部分偈有真人誦讀影片；其餘為手機內建朗讀的近似讀音（不是標準示範）。
- **聖嚴法師這樣說**：依偈文配對的閱讀卡，只放連結與查證過的摘要，不整篇轉載。

## 給使用者：備份與還原

進度、心得、收藏只存在這支手機的瀏覽器裡。**換手機、重新安裝或清除瀏覽器資料前，請先備份。**

1. 到「設定」找到「備份與還原」，按「備份」。
2. 三種方式選一種：傳給自己（LINE 或備忘錄）、存成檔案、複製備份碼。
3. 要還原時，按「還原」，選備份檔或貼上備份碼，先「檢查備份」，再「確定還原」。
4. 還原前會自動留一份目前的資料，之後可按「復原上一次還原」回去。

## 資料存在哪裡

瀏覽器的 localStorage，名稱都以 `dhp2` 開頭：

| 名稱 | 內容 | 是否備份 |
|---|---|---|
| `dhp2` | 最近閱讀、各單元完成狀態與心得 | 是 |
| `dhp2-fav` | 收藏的句子 | 是 |
| `dhp2-remd` | 開啟提醒的日期紀錄 | 是 |
| `dhp2-set` | 設定（色系、字級、字體等） | 是 |

| `dhp2-intro` | 首次開啟的提示記錄 | 否 |

## index.html 裡的主要資料

`BOOKS`（16 品導讀）、`FULL`（T210 全部 39 品，含各偈的巴利對應）、`CAT`、`TL`／`XC`、`DAILY`、`CHG`（版本記錄）、`PV`（真人誦讀影片）、`SY`（聖嚴法師閱讀卡）、`MAPW`／`PNO`（品序對照）。

## 推出新版的流程

```
python3 ver.py <big|minor|micro> "這一版改了什麼（給使用者看的白話）"
sh bump.sh
python3 check.py
```

接著：手機寬度（340、360、390）淺色與深色各看一次 → 請第二位助手複查 → `git push origin HEAD:main`。**推上 main 就會發布到網站。**

- **版號**：`V-4.903` 表示 4 大修、9 小修、03 微調（微調最多 99）。`big` 大修；`minor` 小修（新功能或整品導讀）；`micro` 微調。大修、小修、微調不混用；小修滿 9 會自動進位。
- **更新說明**要寫「使用者可以怎麼用、哪裡變好了」，用長輩看得懂的白話；工程細節寫在 git 提交訊息。
- `check.py` 失敗時不要推出。它檢查的是「有新版」通知依賴的文字格式，格式被改到時通知會悄悄失效。

## 在自己電腦上測試

在專案資料夾執行 `python3 -m http.server 8000`，再開 http://localhost:8000。離線功能（service worker）必須在 localhost 或 https 才會運作，直接雙擊 index.html 開不了。

## 製作守則

- 不任意更動畫面、配色與既有設計；要改版面先問。
- 資料要核實：故事摘要、人名、證果與後續，只寫來源頁有的內容；無法核對的要在畫面與文件寫明。
- 漢巴對應的出處要寫實：編者自己比對的要說明是編者比對；拿不準的寫「相近」，不寫「相同」。
- 偈文對照大正藏 T210，每新增一品要逐偈對到，不漏不重。
- 圖卡有三條繪圖路徑（主圖卡、叮嚀、日行一問），改共用設定時三條都要接，並在三種卡上各看一次。
- 圖卡印章用「法鼓山」三字朱印，不使用法鼓山商標圖形。
- 新增或修改功能後，「設定 → 使用說明」要跟著更新。

## 內容與授權

- 偈文：大正藏 T210（CBETA）。巴利對應與白話參考蘇錦坤整理的對讀資料；安寧品起另標示「蘇錦坤白話版與法句經對讀資料」。
- 聖嚴法師文章：只放公開全集的連結與查證過的摘要。
- 圖卡字體（芫荽、霞鶩文楷 TC、辰宇落雁體、粉圓）為 SIL OFL 授權，由 Google Fonts 載入，需要網路。
- 專案目前沒有附授權檔。內容含節錄與引用，轉用前請先確認出處與授權。

## 已知限制與待辦

- 離線只對「曾經開過」的內容有效；安裝後第一次造訪的頁面要再開一次才能離線使用。
- 圖卡字體靠網路載入，離線時只有曾載入過的字體可用；是否改成內嵌尚待決定。
- 述佛品漢譯第 10 偈的罕用字，部分手機可能顯示為方框。
- 世俗品漢譯第 3 偈：CBETA 與蘇錦坤對照表用字不同。
- 安寧品尚未逐條對照蘇錦坤對照表。
- 設定裡「字體」與圖卡「字體」目前共用同一個設定欄位（`SET.ff`），兩邊的選擇可能互相影響；這是既有行為，尚未處理。
- 其餘待辦（導讀接續、署名考訂、偈數差異等）見「經典」專案內的《法句經工具地圖》與《法句經版本考訂》。
